# y = sin x 上の正三角形が通過してできる立体の可視化(数研出版数学Ⅲ　練習７)


曲線 $C : y = \sin x$ 上の点 P をもとに、xy 平面に垂直に正三角形 PQR を立てます。P の x 座標を $0$ から $\dfrac{\pi}{2}$ まで動かしたとき、この三角形が通過してできる立体を 3D で表示する Web アプリです。

## 問題

曲線 $C : y = \sin x$ 上の点 P を通り y 軸に平行な直線を引き、x 軸との交点を Q とします。線分 PQ を 1 辺とする正三角形 PQR を xy 平面に垂直に作ります。点 P の x 座標が $0$ から $\dfrac{\pi}{2}$ まで変化するとき、正三角形 PQR が通過してできる立体を考えます。

## 数学的な背景

P の x 座標を $t$ とすると、各点の座標は次のようになります（z 軸は xy 平面に垂直で上向き）。

$$
\mathrm{P} = (t,\ \sin t,\ 0), \quad
\mathrm{Q} = (t,\ 0,\ 0), \quad
\mathrm{R} = \left(t,\ \frac{\sin t}{2},\ \frac{\sqrt{3}}{2}\sin t\right)
$$

平面 $x = t$ で切った断面は 1 辺 $\sin t$ の正三角形なので、断面積は

$$
S(t) = \frac{\sqrt{3}}{4}\sin^2 t
$$

です。したがって、$t$ までにできた部分の体積は

$$
V(t) = \int_0^t S(x)\,dx = \frac{\sqrt{3}}{4}\left(\frac{t}{2} - \frac{\sin 2t}{4}\right)
$$

となり、立体全体の体積は次のようになります。

$$
V = V\!\left(\frac{\pi}{2}\right) = \frac{\sqrt{3}}{4}\int_0^{\frac{\pi}{2}} \sin^2 x\,dx = \frac{\sqrt{3}}{4}\cdot\frac{\pi}{4} = \frac{\sqrt{3}}{16}\pi \approx 0.3401
$$

## 主な機能

- **アニメーション**：再生ボタンかスライダーで $t$ を $0 \to \dfrac{\pi}{2}$ と動かし、正三角形 PQR が通過して立体ができていく様子を表示します。
- **立体の色分け**：底面（xy 平面上）、QR 側の面、PR 側の面、現在の切り口を色で区別します。
- **頂点 R の軌跡**：立体の稜線 $\left(x,\ \frac{\sin x}{2},\ \frac{\sqrt{3}}{2}\sin x\right)$ を紫の線で表示します。
- **断面の軌跡**：等間隔に並べた正三角形の枠で、断面がすべて正三角形であることを確認できます。
- **表示の切り替え**：立体、正三角形、断面の軌跡、ワイヤーフレームの表示と、立体の不透明度を変えられます。
- **視点プリセット**：「斜め」「x軸方向」「真上」「真横」の 4 つの視点にすぐ切り替えられます。
- **数値表示**：P の座標、辺 PQ の長さ、断面積 $S(t)$、体積 $V(t)$ をその場で表示します。
- **断面積グラフ**：$S(x)$ のグラフのうち $0 \le x \le t$ の部分を塗りつぶし、その面積が体積 $V(t)$ になることを示します。

## 使い方

1. `index.html` をブラウザで開きます。
2. 「▶ 再生」を押すとアニメーションが始まります。スライダーで $t$ を直接動かすこともできます。
3. マウスで視点を操作できます。

| 操作 | 動作 |
| --- | --- |
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 平行移動 |
| ホイール | ズーム |

| ボタン・設定 | 動作 |
| --- | --- |
| ▶ 再生 / ⏸ 停止 | アニメーションの開始と停止 |
| ⟲ t=0 | 初期状態に戻す |
| t=π/2 | 完成した立体を表示する |
| 速さ | アニメーションの速度を変える |
| ループ | 最後まで行ったら最初から繰り返す |

## 技術的なメモ

- **3D 描画**：[Three.js](https://threejs.org/) r160 と OrbitControls を使っています。
- **座標系**：数学と同じ座標系にするため `camera.up = (0, 0, 1)` とし、z 軸を上向きにしています。xy 平面が床になり、正三角形がその上に垂直に立ちます。
- **立体の生成**：$[0, t]$ を最大 240 個に分割し、底面、QR 側の面、PR 側の面を四角形（三角形 2 枚）でつないで作ります。$t$ が変わるたびに作り直します。
- **数式表示**：外部の数式ライブラリは使っていません。根号は「√」の部分を SVG の折れ線で描き、上の横線を CSS の `border-top` で描いています。分数と積分も CSS で組んでいるので、フォントの有無に左右されずに表示できます。
- **グラフ**：曲線は Canvas 2D で描き、目盛りの数式は Canvas の上に重ねた HTML 要素で表示しています。

## カスタマイズ

`index.html` の次の部分を変えると、表示を調整できます。

| 項目 | 場所 | 内容 |
| --- | --- | --- |
| 立体の分割数 | `buildSolid()` 内の `240` | 大きくすると滑らかになり、処理は重くなります |
| 断面の枠の本数 | 断面の軌跡を作るループの `16` | 表示する正三角形の枠の数 |
| 面の色 | `buildSolid()` 内の `cB`、`cQ`、`cP`、`cE` | RGB（0〜1）で指定します |
| 視点 | `views` オブジェクト | 各プリセットのカメラ位置 |
| 速度の初期値 | `#speed` の `value` | アニメーションの初期速度 |
